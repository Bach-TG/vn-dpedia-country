# Semantic Web Capstone Project

## Project Title

Build a DBpedia Version for the Vietnamese Language

## Overview

The project aims to create a Vietnamese version of DBpedia, following the model of English DBpedia. It involves collecting Vietnamese Wikipedia articles, representing their information using an ontology, transforming the collected data into the 4-star data standard, linking the resulting entities to English DBpedia, and providing an interface for querying the data.

## Required Tasks

1. **Define an ontology.** Establish an ontology to represent the collected information and its relationships.
2. **Collect Vietnamese Wikipedia articles.** Gather Vietnamese-language articles from the Wikipedia website as the project's source data.
3. **Transform the data into the 4-star standard.** Convert the collected data into a representation that satisfies the 4-star data standard referenced in the official brief.
4. **Establish links to English DBpedia.** Find corresponding entities in English DBpedia and create links between them and the Vietnamese dataset.
5. **Provide a query interface.** Enable users to query the resulting data through a SPARQL endpoint or terminal interface.
